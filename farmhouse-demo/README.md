# Fern & Field — Farmhouse Website Concept

A responsive, single-page farmhouse stay discovery concept inspired by boutique hospitality and Airbnb-style browsing.

## Preview deployment — Cloudflare Pages

Create a Cloudflare Pages project using **Workers & Pages → Create → Pages → Import an existing Git repository**.

- GitHub repository: `mohitparmar110/Sample-websites`
- Production branch: `main`
- Framework preset: `None`
- Build command: *(leave empty)*
- Build output directory: `farmhouse-demo`
- Root directory: repository root

Cloudflare will issue a `<project-name>.pages.dev` URL after deployment. This repo can hold multiple independent prototypes in separate directories.

## Features

- Responsive editorial farmhouse landing page
- Sample listings in Karjat, Lonavala and Alibaug
- Destination and capacity filtering on the client
- Check-in and check-out date inputs (UI only)
- Save/heart buttons (UI state only)
- No payment or reservation backend

**Important:** All sample property details, ratings and prices are fictional placeholders. Hero and listing images are loaded from Unsplash. Replace content and assets before production use. The original Airbnb-style HTML referred to in the brief was not present in the repository at time of authoring.

Open `index.html` in a browser to preview locally.
